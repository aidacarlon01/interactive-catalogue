About this build

A sample course that shows a production Canvas theme working the way learners actually meet it.

I designed and coded this theme for a university's online AI and data analytics programs, delivered in Canvas LMS. Instead of showing it as a list of components, this site puts the theme inside a short course: a home page and four content pages, connected the way modules and topics are in a live course. The copy is style guide copy, so each component explains itself, and no real course content is used.

What I built

  • The theme stylesheet: design tokens drawn from the university's published brand palette, with every colour pair checked for WCAG contrast. All styles are scoped to authored page content, so Canvas's own interface is never affected.
  • The theme script: small, self-contained modules that enhance authored markup: the page banner, transcript and glossary dialogs, the image lightbox and card navigation. One shared content watcher re-runs them whenever Canvas re-renders part of a page, and each module is safe to run more than once.
  • The component set: the authored markup a learning technologist pastes into the Rich Content Editor, documented in an internal style guide and used across every course in the program.

Accessibility decisions

Design choices made for WCAG 2.2 AA
DecisionWhy
Inline links keep their underlineColour is never the only cue (1.4.1 Use of Color)
Dialogs move focus into themselves, keep it there and hand it back on close; the background is made inertKeyboard and screen reader users stay oriented (2.1.2, 2.4.3)
Accordions use native details and summaryFully accessible with no script to fail
Image zoom is opt-in per imageDecorative images and icons stay out of the tab order
Glossary terms stay inlineKeeps the inline exception for target size (2.5.8)
Transcripts are authored in the pageIf the script fails, the text is still there
Banner titles are real text from the page headingThe page keeps its accessible name; the image is decorative

How this static version differs from Canvas

The page bodies, theme stylesheet and theme script are the production files. Around them, this site recreates the Canvas frame (navigation, breadcrumb and module footer) in a separate stylesheet. Three things change for the web:

  1. Videos are placeholders, because course videos belong to the client.
  2. The Canvas icon font isn't available, so well icons are inline SVG.
  3. The H5P resizer module is swapped for one that sizes the embedded catalogue interactives.
