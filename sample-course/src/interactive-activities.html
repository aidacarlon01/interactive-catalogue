Course in review

In this sample course, you've seen that:

  • A shared component set means learners only have to learn how a course works once.
  • Contrast, underlined links and a clear heading outline make a page readable for every learner.
  • Every video, image and interactive needs an alternative that carries the same learning.
  • Accessibility is designed into each component, not checked at the end.

Key terms

Select a letter to jump to its terms.

ABCDEFGHIJKLMNOPQRSTUVWXYZ

A

Alt text
A short text alternative for an image that says what it shows and why it matters. Screen readers read it aloud in place of the image.

C

Component
A reusable building block of a course page, such as a callout, a card or an accordion, that looks and behaves the same wherever it's used.
Contrast ratio
How much lighter one colour is than another, from 1:1 to 21:1. Body text needs at least 4.5:1 against its background.

F

Focus indicator
The visible outline that shows which element has keyboard focus, so a learner using the Tab key always knows where they are.

T

Transcript
The full text of a video's spoken content, including any on-screen text that matters.

W

WCAG 2.2 AA
Level AA of the Web Content Accessibility Guidelines, version 2.2: the accepted baseline for accessible web content.
