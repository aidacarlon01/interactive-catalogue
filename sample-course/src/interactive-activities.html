Interactive activities

Practice that learners do, not just read: built as standalone HTML interactives and embedded in the page.

Each activity below is a placeholder from the interactive pattern catalogue. Every one is a single self-contained HTML file built to the same brand and accessibility rules as the theme: it can be used with a keyboard alone, it never relies on colour to show state, and it reports its height so the page can size the frame.

How these activities are made

A learning designer picks a pattern from the catalogue and fills in its seven-heading brief (Purpose, Layout, Interaction, States, Content, Slug, Target) with the real course content. The interactive is then built from that brief, committed to GitHub, uploaded to the course files, and embedded on the page.

Explore: card-grid selector

Use a card-grid selector when learners need to compare several related ideas but only read one in depth at a time. Select a card to show its detail panel.

Pattern: card-grid selector (view its brief in the catalogue).

Step through: tabs and stage stepper

Use a stepper for a process with a fixed order. Learners can jump to any stage with the tabs, or work through in order with Next and Previous.

Pattern: tabs and stage stepper (view its brief in the catalogue).

Practise: drag-and-drop classifier

Use a classifier when learners need to sort examples into categories and get feedback. Every card can also be placed with a menu, so the activity never depends on dragging.

Pattern: drag-and-drop classifier (view its brief in the catalogue).
