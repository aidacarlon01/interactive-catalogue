Welcome to the sample course

A working course, built from the theme's components, where the copy explains each component.

This sample course shows the theme the way a learner meets it: inside a course, page after page. Each page uses the same authored components a learning technologist pastes into the Canvas Rich Content Editor, and the stylesheet and script that style and enhance them are the ones that run in production. The only thing that changes is the copy. Instead of subject content, each component describes what it's for and how to use it.

A course home page usually needs a small set of components: a page banner, a few paragraphs of welcome text, a video with its transcript, a note, a pull quote, and a set of cards that lead into the rest of the course. That's everything on this page, top to bottom.

Transcript: Welcome to the sample course

This is where the video transcript lives. It's authored directly below the video in the page body, so if the theme script ever fails to load, the full text stays visible on the page and nothing is lost.

When the script is running, the transcript is hidden from the page and opens in this dialog instead. The dialog moves focus to its close button when it opens, keeps the Tab key inside it, closes with Escape, the close button or a click on the backdrop, and returns focus to the Transcript button when it closes.

While the dialog is open, the rest of the page is hidden from screen readers and can't be reached with the keyboard, so the dialog is genuinely modal rather than just visually on top.

Write transcripts in plain paragraphs. Use a heading for each speaker or section if the video is long, and keep any on-screen text that matters, such as figures or slide titles, in the transcript too.

Note

How to use a note

Use a note for the one thing a learner must not miss on this page: a file to download, a date that moves, or a change to the usual pattern. Keep it to a few sentences. One note per page keeps its weight; three notes on a page means none of them stand out.

A pull quote slows the reader down. Use it for the one idea a page turns on, keep it short enough to read in a single breath, and always credit its source.
