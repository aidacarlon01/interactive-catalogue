Building a consistent course

Why every page in a course should look and behave the same, and what that takes.

Learners spend their first few minutes in any course learning how it works: where the next step is, what a callout means, how to open a transcript. When every page follows the same patterns, they only have to learn that once. When each page is built differently, they relearn it on every page, and that effort comes straight out of the time they have for the content.

Consistency doesn't happen by accident. It comes from a small, agreed set of components, a theme that styles them the same way everywhere, and a build process that uses nothing else.

What you'll learn on these pages

By the end of this sample course, you'll be able to:

  • Explain why a shared component set makes a course easier to learn from.
  • Recognise the design choices that make a page accessible to every learner.
  • Identify an accessible alternative for each kind of media.
  • Check your understanding with interactive practice activities.

Case study: one program, many builders

Start with a case you can return to as you work through the pages.

Case: the six-module rebuild

An online program runs four courses of six modules each. Over two years, its pages have been built by several people, each with their own habits. Some callouts are blue boxes, some are bold text, some are tables with one cell. Some links open new tabs and some don't. Transcripts sit under some videos, in a separate file for others, and are missing for a few.

Learners haven't complained about any one page. But support requests keep asking the same questions: where is the transcript, what does this box mean, how do I get to the next topic. The program team decides to rebuild every page from one shared set of components before the next intake.

The rebuild takes a few weeks. Each page loses its one-off formatting and gains the same banner, the same callouts and the same navigation. Nothing about the teaching changes, but the support questions about finding things largely stop.

Case reflection

Take a moment to reflect on these questions:

  • Think of a course you've taken online. What did you have to work out before you could focus on the content?
  • Why might learners ask "where is the transcript?" rather than report that a transcript is missing?
  • What would you need to agree on before a team of builders could work from one component set?

Keep these questions in mind as you work through the next pages.
