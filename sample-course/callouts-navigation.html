2. Callouts and navigation

Callouts and navigation

Components that make content stand out and show learners where to go next.

Callouts pull one piece of content out of the flow of a page. Navigation components move a learner between pages. Both work best when they're used sparingly: if everything is highlighted, nothing is.

Wells

A well is a callout with a heading bar and a content panel. The icon and heading name the kind of callout, so learners can tell a reminder from a task before they read it. These three cover most needs.

Note

Use a note for information a learner must not miss, such as a download or a date. Keep it short and use one per page.

Reflect

Use a reflection well to give learners questions to think about. They aren't graded, so a short list works best:

  • Which component on this page would you reach for first, and why?
  • Where in your own courses would a callout help a learner, and where would it get in the way?

Apply your learning

Use an activity well when the page stops explaining and asks the learner to do something. Say what to make, where to put it, and roughly how long it should take.

For example: list three pages in a course you know well, and name the one component each page is missing. Spend about 10 minutes on it.

Glossary terms

Key terms in the body text open their definition in a small dialog, so learners can check a word without leaving the page. Try component or WCAG 2.2 AA. The term is authored as a span with its definition in data attributes, because Canvas removes button elements from page content. The theme script makes it keyboard-operable when the page loads.

Topic cards

Cards are the main way learners move through a module. Each card is a single link: an eyebrow for the topic number, a title, and pills listing the activities inside. Hover over a card or tab to it and it fills with Monash Blue.

Action cards and buttons

Action cards give a learner a choice between a few clear next steps. Each one pairs a short sentence with a single button. Buttons are outlined in Monash Blue and fill when hovered or focused.

Use an action card to send learners to the start of the course or module, with the overview, schedule and tips for success.

Course home

Use a second card for the other common route, such as support, community or the module list, so learners can continue where they left off.

Glossary page

A course glossary collects every term learners meet in a course. The letter bar jumps to each section, and letters with no terms are greyed out and can't be selected, so nobody follows a link to an empty section.

A

Accordion
A heading that opens to show more content beneath it. Built from native details and summary elements, so it works with a keyboard and screen reader without script.
Action card
A panel that pairs one sentence of context with one button, used to offer a clear next step.

C

Card
A single link styled as a tile, with an eyebrow, a title and optional activity pills. Used to move between topics and modules.
Component
A reusable piece of authored page markup that the theme styles and, where needed, enhances with script.

F

Focus ring
The visible outline that shows which element has keyboard focus. The theme draws it in a high-visibility blue on every interactive component.

T

Transcript
The full text of a video's spoken content, opened in an accessible dialog from the button below the video.

W

Well
A callout with a heading bar and a content panel, used for notes, reflections and activities.
