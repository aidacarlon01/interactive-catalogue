3. Media

Media

Video, images and embedded interactives, each with an accessible alternative built in.

Media carries a lot of the teaching in an online course, and it's also where accessibility most often breaks. Each media component here ships with its alternative: a transcript for video, alt text and an accessible zoom for images, and a title and keyboard support for embeds.

Video template

The video template frames a hosted video with a title above it and a Transcript button below. The frame holds a 16:9 ratio at every screen width, so the video never letterboxes or overflows on a phone.

Parts of the template

The template has four parts: a Heading 4 title, a video container that holds the provider's iframe, the transcript itself, and a link that opens it.

Authoring the transcript

Paste the transcript into the transcript block below the video. Give the block an id, and point the Transcript link at it with aria-controls. The theme script does the rest: it stops Canvas turning the block into its own plain dialog, then shows the text in this styled one.

If the script doesn't load

The transcript stays on the page as ordinary text, so learners can still read it.

Zoomable images

Diagrams with small labels can be marked as zoomable. Select the image below, or tab to it and press Enter, to open it full screen. Press Escape or the close button to return to the page.

Embedded interactives

Interactives and H5P activities embed as iframes. Give every iframe a title that says what it is, because that's what a screen reader announces. The frame resizes itself to its content height, so learners never scroll inside a box within the page.

Note

Every image needs alt text that says what the image shows and why it matters on this page. If an image is purely decorative, give it an empty alt (alt="") so screen readers skip it. Banners are decorative, which is why the page title in each banner is real text, not part of the picture.
